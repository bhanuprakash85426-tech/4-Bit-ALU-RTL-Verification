# 4-Bit-ALU-RTL-Verification
Designed and verified a 4-bit Arithmetic Logic Unit (ALU) using Verilog RTL. The ALU supports 8 operations: addition, subtraction, AND, OR, XOR, NOT, left shift, and right shift. Developed a functional testbench to simulate and verify ALU outputs, carry, and zero flag functionality using an online Verilog simulator.
